# Ayah Abd Elhasip — Portfolio

Personal portfolio of **Ayah Abd Elhasip**, a Frontend Developer.
Built with **React + Vite**, featuring an editorial design in burgundy & cream,
scroll-reveal animations, a 3D tilt effect, a skills marquee, and a lanyard-style ID badge.

## Tech

- React
- Vite
- Plain CSS (custom design system)
- Fraunces + Inter (Google Fonts)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Editing content

All content lives in one place: `src/data/portfolio.js`
(profile, projects, skills, experience, education).
